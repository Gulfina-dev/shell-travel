# Shell Travel

## Description
A one-page travel agency website with a booking form and a gallery of destinations.

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (vanilla, no libraries)

## Features
- Fully responsive design (mobile-friendly)
- Tour slider
- Booking form with validation
- Selected tours saved in LocalStorage

## Future Improvements
- Add backend with Node.js
- Connect a database to store bookings
